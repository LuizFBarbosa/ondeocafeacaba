## Frases do quadro branco

- Se funcionar, você nunca mais vai ouvir Dona Fátima chegar estressada às 7h50.
- Sempre TRIM.
- O inimigo pode ser a versão anterior de você mesmo.
- Mais alerta não é mais segurança.
- Uma métrica sem intervalo de confiança é uma opinião com casas decimais.
- Um dado pessoal não é informação qualquer. É confiança.
- Ferramenta que admite o que não sabe é mais confiável do que ferramenta que finge saber tudo.
- A simulação não dá a resposta certa — ela nos ensina a perguntar melhor.
