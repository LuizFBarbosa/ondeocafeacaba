# Capítulo 9 — O Painel do Futuro

**Dashboards • Streamlit • Plotly Express**

---

## Frase do Sr. Ricardo

> “Eu quero ver o filme enquanto ele tá sendo filmado.”

Relatório te diz o que aconteceu. Dashboard te faz perguntar **por quê**.

---

## Como executar

```bash
pip install streamlit plotly pandas numpy
streamlit run dashboard.py
```

---

## Checklist de um bom dashboard

- [ ] O que aconteceu?
- [ ] Onde aconteceu?
- [ ] Quanto custa?
- [ ] Preciso agir hoje?
